# MAP-TEAM-003 市场／患者体验合伙人共同设计邀请包 V1.0

## 1. 现在为什么可以加入

她加入时接管的不是代码，而是“患者为什么愿意来、是否敢说、能否坚持、是否愿意推荐”的决策权。没有正式客户端并不妨碍这项工作；相反，越早参与，越能避免产品语言和流程由开发者单方面决定。

现阶段使用两类材料：

1. 合成评审门户：<https://map-tcm-synthetic-review.jordamo.chatgpt.site/>
2. Gate 0 可点击客户端骨架：门户首页进入“Gate 0 客户端骨架”；本地开发期间也可暂由 Aster 演示。

全程只使用 `SYN-PAT-*` 合成身份，不输入本人真实病史、姓名、电话、照片、报告或其他隐私资料。

## 2. 她接管的职责

- 患者旅程负责人：邀请、理解、授权、记录、问诊、行动、复诊、长期趋势。
- 信任语言负责人：判断哪些文字让患者安心，哪些文字令人误解、羞耻或警惕。
- 市场验证负责人：验证目标人群、核心问题、价值主张、参与门槛、推荐意愿和触达方式。
- 患者侧验收人：患者体验相关需求未经她或未来同职能负责人确认，不进入“体验已验收”。

她不承担医学判断、处方审核、软件安全批准或生产发布责任。

## 3. 第一周共同设计流程

### 会前：15–20 分钟独立体验

1. 打开合成评审门户，选择“我是患者体验者”。
2. 使用代号 `SYN-PAT-001`。
3. 仅根据页面给出的合成案例完成全流程。
4. 导出 JSON 评审结果；不要在微信群发送任何真实健康资料。
5. 走查 Gate 0 患者视角，记录三个“最想继续用”和三个“会让我退出”的时刻。

### 第一次会议：45 分钟

- 10 分钟：她用自己的话描述“这个产品到底替患者解决什么”。
- 15 分钟：逐步审查患者旅程与信任边界。
- 10 分钟：选出首批最值得验证的一类用户，不急于覆盖所有人群。
- 10 分钟：确定下一轮原型修改与三项验证指标。

### 会后：一页验收结论

她只需给出：

- 保留：最有价值的三个环节。
- 修改：最不可信、最费力或最难懂的三个环节。
- 缺失：患者真正需要、当前却没有的一个环节。
- 假设：首批目标患者是谁，以及为什么愿意尝试。
- 指标：完成率、理解度、信任度、再次使用意愿、推荐意愿中本轮最重要的三项。

## 4. Gate 0 市场验证边界

可以验证：问题是否真实、语言是否清楚、流程是否可完成、信任是否建立、用户是否愿意再次参与或推荐。

暂不验证：大规模获客、付费转化、医学疗效宣传、自动诊疗或任何基于真实病历的数据训练。
