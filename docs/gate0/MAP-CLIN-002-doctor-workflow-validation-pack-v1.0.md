# MAP-CLIN-002 真人医生临床工作流验收邀请包 V1.0

## 1. 医生现在接管什么

医生不是来替开发团队写需求，而是接管临床工作流的最终解释权与验收责任：问什么、按什么顺序问、什么可以缺失、什么必须追问、AI 可以起草什么、哪些内容必须由真人医生确认。

现阶段不是临床试验，不接诊，不输入真实病历，不验证疗效。只验证“这个流程是否符合真实中医工作，以及安全边界是否清楚”。

1. 打开合成评审门户：<https://map-tcm-synthetic-review.jordamo.chatgpt.site/>

禁止把真实患者姓名、联系方式、照片、检查报告、方剂或可重新识别患者的细节带入网页、聊天群、GitHub Issue 或演示记录。

## 3. 医生验收清单

### 临床顺序

- 第一个问题是否正确。
- 主诉、病程、既往资料、用药过敏、四诊与复诊变化的顺序是否自然。
- 远程无法完成的望闻问切内容能否明确标记“未采集”，而不是被推测补全。
- 敏感问题是否有临床必要性说明并允许患者拒答。

### 信息质量

- 每条重要信息是否有来源、时间和状态。
- “未知”“未问”“患者拒答”“不适用”是否被区分。
- 初诊与复诊能否看出变化，而不是反复复制整份病历。

### AI 边界

- AI 可做：整理、摘要、问题建议、缺失提醒、来源锚定、版本比较。
- AI 不可做：独立诊断、辨证定论、治则定论、处方、签署、隐瞒不确定性。
- 医生必须能逐项修改、拒绝和确认草稿；最终责任不能被“AI 建议”稀释。

### 安全升级

- 危险信号是否会中止普通流程并提示线下医疗或急诊。
- 不良事件和症状明显加重是否在复诊中有独立入口。
- 没有足够资料时，系统是否允许医生选择“不形成方案”。

## 4. 第一轮会议建议

- 20–30 分钟：医生独立走查网页并导出评审结果。
- 45–60 分钟：共同审查字段顺序、缺失状态、AI 边界与复诊闭环。
- 15 分钟：形成“必须修改／可后置／可验收”的裁决。

三位医生可以先独立评审，再安排一次会诊式讨论。差异不应被简单平均，而应记录各自临床流派、适用场景和理由。
