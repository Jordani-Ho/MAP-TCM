# MAP-003｜中医临床记录协议（最小可用版）

## 记录对象

一次 `Encounter` 表示一次初诊、复诊、随访或医生复盘。每条字段均应保存 `source`（患者/医生/文件/AI）、`author`、`recorded_at`、`version` 和 `review_status`。

## 必填结构

```text
Encounter
├─ 基本信息：患者标识、就诊类型、时间、医生
├─ 原始资料：主诉、现病史、既往史、用药/过敏、检查附件
├─ 四诊：望、闻、问、切（允许未知/未采集）
├─ 医生判断：病名、证候、病机、辨证依据、鉴别要点
├─ 处理：治则治法、处方/非药物建议、加减理由、医嘱
├─ 结果：疗效评价、不良反应、下次计划
└─ 审核：草稿、审核、签署、修订/撤回与原因
```

## 关键规则

1. 四诊资料与医生判断分开存放，不能把 AI 推测写成患者事实。
2. “病名/证候/治则/处方”只由具备权限的医生签署后成为正式记录。
3. 允许不确定值；缺失信息不得由 AI 静默补全。
4. 处方变更需关联上一版本并填写变更理由。
5. 患者摘要只可引用医生已签署且授权展示的内容。

## 审核状态

`draft`（草稿）→ `doctor_reviewed`（已审核）→ `signed`（已签署）。  
签署后修改产生新版本；`withdrawn` 只撤回有效性，不删除审计历史。
