# MAP-005｜医疗记忆与证据模型

## 四层记忆

1. **原始记录层：** 患者陈述、医生录入、原始附件；不可被 AI 改写。
2. **临床事件层：** 经医生审核的就诊、辨证、处方、随访和疗效事件。
3. **医生个人知识层：** 医生主动沉淀的偏好、经验与教学材料，隔离保存、可撤回授权。
4. **外部证据层：** 经典文献、指南、论文等，必须有来源、版本和适用范围。

## 证据标签

任何显示给医生的总结或检索结果至少带一个标签：`patient_fact`、`doctor_judgment`、`ai_draft`、`external_evidence`、`unknown`。系统不得把这些标签合并成未经说明的“结论”。

## 检索与生成

AI 可基于当前患者授权数据和医生允许的知识范围检索，输出中必须给出引用定位。生成病历草稿时，未找到来源的内容标为“待确认”，不能写入正式字段。医生个人经验不能自动用于其他医生或公共训练。

## 质量控制

记录冲突、来源缺失、过期证据和不确定性必须可见；医生可纠正、拒绝或标记 AI 草稿。所有草稿—修改—签署的链路形成可回溯版本历史。
