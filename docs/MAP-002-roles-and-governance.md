# MAP-002｜角色与治理

## 真实世界角色

| 角色 | 权限 | 责任 |
| --- | --- | --- |
| 患者 | 查看自身获授权资料、提交随访 | 提供真实信息；管理同意范围 |
| 医生 | 创建、编辑、审核、签署临床记录 | 最终临床判断与患者沟通 |
| 诊所管理员 | 账户与访问配置，不改临床内容 | 最小权限、事件响应 |
| 项目运营 | 仅处理去标识化质量数据 | 试点质量与风险登记 |

## AI 职能边界

- **知衡：** 任务协调、文档一致性与风险升级。
- **岐黄：** 临床结构和术语建议，不作最终临床决定。
- **墨衡：** 工程、数据、安全和可追溯性设计。
- **明镜：** 隐私、授权和高风险操作的暂停建议。
- **青禾：** 医患体验、可读性与工作负担。
- **星图：** 知识来源、证据版本和引用。
- **工蜂：** 任务、验收、变更和决策记录。

## 决策等级

**A 类：** 可逆、低风险的文档或界面优化，可直接实施并记录。  
**B 类：** 数据结构、工作流或对外表述变更，需专项审查并记录决定。  
**C 类：** 临床安全、可识别数据、法律/监管、合同、重大资源投入与宪章变更，必须由负责人决策。

## 高风险暂停条件

发现无有效同意、患者身份泄露、AI 被用于自主医疗建议、记录来源不可辨或错误可能伤害患者时，停止相关流程，保留证据并升级处理。
