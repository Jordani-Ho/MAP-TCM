# MAP-001｜Alpha 产品边界

## 用户与场景

| 用户 | 核心任务 | 系统提供的帮助 |
| --- | --- | --- |
| 医生 | 初诊、复诊、随访、复盘 | 结构化记录、差异比较、病历草稿、审核 |
| 患者 | 提供症状变化、查看授权信息 | 提醒、时间线、医生审核后的摘要 |
| 管理员/项目方 | 管理诊所或试点 | 账户、权限、审计与风险处置 |

## P0 功能

1. 患者档案与知情同意状态。
2. 初诊/复诊表单：主诉、现病史、既往史、四诊、检查资料、生活方式。
3. 医生可编辑的病历草稿，字段级保存来源。
4. 医生填写辨证、治则治法、处方及加减理由。
5. 复诊差异比较与症状/疗效时间线。
6. 审核、签署、修订、撤回和审计日志。
7. 医生审核后生成患者可读摘要。

## 非功能要求

- 所有临床写入均保留作者、时间、版本和来源。
- 默认最小权限；患者只能访问被授予的自身资料。
- AI 输出必须标记为“草稿”，直到医生签署。
- 对敏感字段、导出、分享、权限升级建立审计事件。

## 明确延后

语音/图像自动诊断、多医生协作网络、自动处方建议、公共知识训练、医保结算、面向患者的自主问诊与跨机构 EHR 对接，均不属于 Alpha 范围。
