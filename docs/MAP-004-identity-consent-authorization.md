# MAP-004｜身份、同意与授权

## 身份模型

系统为每位患者、医生和工作人员建立独立不可复用的内部标识。显示名称、联系方式和临床记录分层保存；分析与产品测试默认使用去标识化副本。

## 同意模型

同意不是一次性勾选，而是一条带范围的记录：

| 字段 | 说明 |
| --- | --- |
| subject | 授权主体（患者或合法代理人） |
| purpose | 诊疗记录、随访、去标识化改进等目的 |
| scope | 可访问的资料类别与人员 |
| effective_at / expires_at | 生效与失效时间 |
| revocation | 撤回时间、范围与后续处理 |

## 最小权限

- 医生只能访问其照护关系内的患者资料。
- 患者只访问经医生签署且授权呈现的自身资料。
- 管理员不默认具有临床内容阅读权。
- AI 服务仅获得完成当前任务所需的最少字段。

## 撤回与导出

撤回后应立即停止新的非必要处理和共享；既有临床记录按适用保存规则处理，但必须标记权限变化。所有导出、分享、批量查询和权限变更记录审计事件；不提供无审计的“全量下载”。
