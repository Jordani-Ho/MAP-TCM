# TCM-CLIN-001｜合成病例评审脚本

> 纯虚构产品测试材料。不得用于诊疗，也不对应任何真实个人。

## 合成角色

- 合成标识：`SYN-CLIN-001`
- 身份属性：成年人；评审中不提供姓名、电话、地址、证件或真实影像
- 场景：希望改善近阶段睡眠与白天精力，已同意使用合成资料完成产品设计演练

## 第一次就诊输入

合成患者陈述：

> 约三周来入睡比平时慢，夜间偶尔醒，晨起觉得精神不足。工作节奏变化后更明显，休息日稍缓解。食欲大致如常，近几天口渴感略多。没有提供既往检查附件，也说不清曾用保健品的完整名称。

评审人员按医生追问逐步提供以下合成答案，不要一次性展示全部：

- 当前药物/方药：自述无固定处方药；保健品名称 `unknown`，待确认；
- 过敏与不良反应：`unknown`，未携带资料；
- 急症/危险信号：由评审医生按其认为必要的问题完成合成筛查；本脚本不预填“无异常”；
- 寒热、汗、疼痛、胸腹、饮食口渴、二便、睡眠精力、情志：允许医生决定顺序和追问粒度；
- 生殖相关问题：只有医生判断适用且有安全必要时才进入；合成角色可回答 `declined`；
- 舌象：不提供真实照片；医生可用“未采集”测试缺失状态；
- 脉诊：远程产品演练，标记 `not_collected`；
- 医生判断与计划：由医生在评审中说明页面需要哪些字段，但不要求形成真实诊断或处方。

观察并记录：医生实际顺序、认为必须追问的字段、愿意跳过的字段、需要保留原话的内容，以及字段缺失时是否能继续审核。

## 合成复诊输入

时间设定为合成初诊后一周。仅用于测试信息结构：

- 入睡时间自述略有缩短，但夜醒次数“说不清”；
- 白天精力变化不明显；
- 合成患者执行了“规律记录睡眠时间”的非诊疗观察任务约五天，中断两天；
- 没有可确认的方药暴露；
- 自述没有新增明显不适，但危险信号仍需重新人工确认；
- 新增药物、检查或其他治疗：`unknown`，需追问；
- 舌象和脉诊仍可由医生选择采集或标记 `not_collected`。

让医生决定：

1. 复诊第一屏最需要看到什么；
2. “略改善”“不明显”“说不清”应如何结构化又保留原话；
3. 执行不足与疗效不确定如何区分；
4. 哪些初诊字段必须并列显示，哪些只在需要时展开；
5. 如果医生改变判断或干预，必须填写什么理由并引用哪个版本。

## 禁止记录

- 评审医生或任何真实患者的个人信息；
- 真实处方、真实影像、真实检验报告或聊天记录；
- 把本脚本内容标为医生已经审核或签署；
- 将 AI 生成内容伪装成患者事实或医生判断。
