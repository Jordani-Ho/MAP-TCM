# TCM-CLIN-001｜初诊/复诊字段字典（医生评审候选版）

版本：0.1.0
状态：Candidate for Doctor Review
适用范围：合成病例产品设计，不用于真实诊疗

## 目的

本字典把 MAP-003、MAP-005 与 MAP-007 的临床记录原则转换为可评审、可测试的字段合同。它是工程候选基线，不代表临床专家已经确认，也不把特定流派的问诊顺序固化为唯一标准。

机器可读规范见 [`schemas/tcm_clinical_fields_v0.1.json`](../../schemas/tcm_clinical_fields_v0.1.json)。医生评审只需使用合成病例，并在评审表中决定保留、修改、移动、合并或删除。

## 字段值共同外壳

每个字段值都必须独立保存：

| 元数据 | 作用 |
| --- | --- |
| `value` | 原始值或明确的未知状态 |
| `source_role` | 患者、医生、系统或文件；AI 草稿另行标记 |
| `author_id` | 实际录入或确认者 |
| `recorded_at` | 记录时间 |
| `review_status` | `draft`、`doctor_reviewed`、`signed` 或 `withdrawn` |
| `version` | 修订链中的版本；已签署值不得静默覆盖 |

缺失状态统一为 `unknown`、`not_collected`、`not_applicable` 或 `declined`。系统不得把空白自动解释为“无异常”，也不得让 AI 猜测补齐。

## 初诊最小顺序

| 顺序 | 字段组 | 主要内容 | 默认要求 |
| --- | --- | --- | --- |
| 1 | 就诊与授权 | 合成患者标识、就诊类型、时间、有效同意引用 | 必填 |
| 2 | 主诉与目标 | 最困扰问题、患者期望 | 主诉必填，目标建议 |
| 3 | 病程与安全 | 起病/变化、诱因、既往处置、药物、过敏、危险信号 | 核心安全项必填，允许未知 |
| 4 | 望诊 | 神色形态、舌质、舌苔、可选媒体引用 | 建议；媒体可跳过 |
| 5 | 闻诊 | 声音、言语、呼吸；有临床必要时记录气味 | 建议/条件性 |
| 6 | 问诊 | 寒热、汗、头身、胸腹、饮食口渴、二便、睡眠精力、情志 | 建议；允许未知/拒答 |
| 7 | 条件性问诊 | 月经、生殖、妊娠/哺乳 | 仅适用、相关且愿意回答时 |
| 8 | 切诊 | 脉诊及其他实际实施的触诊 | 建议/条件性；远程可标未采集 |
| 9 | 医生判断 | 病名、证候、病机依据、鉴别与不确定性 | 只由医生确认；签署门禁 |
| 10 | 计划 | 治则治法、干预版本、医嘱、观察点、下次计划 | 只由医生确认；干预按条件记录 |

## 复诊最小顺序

复诊先复核安全和实际发生的变化，再做医生判断：

1. 本次主诉与新的危险信号；
2. 距上次记录的新增、改善、加重、不变和未知；
3. 实际干预暴露、执行、中断与新增治疗；
4. 疗效、不良反应与患者体验；
5. 复查四诊中本次实际采集的项目；
6. 引用上次已签署记录进行医生前后比较；
7. 记录证候/病机变化、干预调整理由和下一步计划。

## 资料类型边界

| 类型 | 可由谁产生 | 能否直接成为正式医生判断 |
| --- | --- | --- |
| `patient_fact` | 患者陈述，医生可代录并注明来源 | 否 |
| `doctor_observation` | 医生实际观察或检查 | 否，仍需与判断分开 |
| `doctor_judgment` | 有权限的医生 | 是，但必须审核和签署 |
| `ai_draft` | AI 在授权数据范围内生成 | 否；不得自动写入医生判断或签署 |
| `external_evidence` | 有来源和版本的外部资料 | 否；只能作为证据 |
| `unknown` | 任何未确定或未采集状态 | 否；必须可见 |

## 隐私与临床安全规则

- 工程仓库和评审材料只允许 `SYN-` 合成标识，不放姓名、电话、精确地址、证件号、真实影像或原始病历。
- 情志、生殖、月经、妊娠、气味、二便和触诊等敏感字段不得无条件强制。
- 急症/危险信号字段只触发既定人工流程，不由系统作自主分诊结论。
- 诊断、辨证、治则、处方及调整理由只能由医生确认和签署。
- 字段字典确认后才能进入 TCM-ENG-003；本候选版通过测试不等于通过医生评审。

## 0.1.0 待医生确认事项

1. 初诊与复诊的实际问诊顺序是否符合门诊节奏；
2. 哪些“建议”字段应改为必填或可跳过；
3. 舌象、脉象的结构化粒度是否足以比较又不会增加负担；
4. 危险信号、用药、过敏及妊娠相关安全问题是否遗漏；
5. 复诊的疗效、依从性和干预变化是否能支持真实复盘；
6. 是否存在流派专属字段，应作为医生配置而非公共核心字段。
