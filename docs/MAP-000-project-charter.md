# MAP-000｜项目宪章

**版本：** 0.1  
**状态：** 草案  
**项目：** AI中医病历助手（MAP）

## 使命

构建一个安全、可追溯、医生主导的中医临床 AI 学徒：它将临床资料转为连续、结构化、可复核的记录，帮助医生传承与反思诊疗经验，帮助患者理解并保存自己的健康历程。

## 第一阶段目标

交付 MAP Clinical Apprentice Alpha，覆盖：病历草稿、四诊记录、辨证理由、处方记录、疗效/复诊比较、患者时间线和审核后的随访摘要。

## 不可突破的原则

1. AI 是记录者、整理者、检索者和学徒，不是执业医生。
2. 医生对诊断、辨证、处方和患者沟通拥有最终决定权。
3. 病例必须有合法来源、最小化采集和可验证授权；默认优先去标识化。
4. 每项结论必须可区分为原始事实、医生判断、AI 生成或外部证据。
5. 高风险、不确定或证据冲突的内容必须显式呈现，不得伪装成确定事实。
6. 医生个人经验归医生控制；患者资料归患者与其授权范围控制。

## Alpha 禁止项

- 自主诊断、开方、改方或承诺疗效；
- 无医生审核向患者输出临床结论；
- 跨医生自动迁移个人诊疗经验；
- 将可识别患者资料用于公共模型训练或未经授权分享；
- 把系统定位为医疗机构合规病历系统，直至完成相应合规建设。

## 成功标准

首轮试点不以收入或用户量评估。成功意味着：医生愿意持续使用；病历整理时间下降；医生认为其思路被忠实呈现；患者能看懂经审核的摘要；所有高风险输出都经过审核与留痕。
