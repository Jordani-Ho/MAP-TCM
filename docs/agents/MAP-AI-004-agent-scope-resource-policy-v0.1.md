# MAP-AI-004｜智能体任务范围与资源保护策略 0.1

- 状态：Synthetic Engineering Baseline / Not Production Ready
- 日期：2026-08-22
- 适用角色：医师智能体徒弟、患者健康辅导员

## 决策

MAP 智能体不是通用聊天助手。只有与中医、健康、当前使用者本人、当前获授权照护任务，或 MAP 产品的隐私与安全使用直接相关的请求，才能进入知识检索或模型调用。其他请求在读取私域和调用模型前，以最短固定文本拒绝。

固定拒绝语：

> 这个问题不属于本智能体的中医、健康或个人知识服务范围，因此不予处理。

## 允许范围

1. 中医经典、理论、医史、来源和学习；
2. 健康、生活习惯、饮食、起居、二便、情志、活动、环境和治未病；
3. 使用者本人的健康资料、学习记录和个人知识库；
4. 当前获授权患者的接诊、复诊、会诊和随访；
5. 真人医生已确认的方案、执行、反馈和复盘；
6. MAP 账户、隐私、授权、资料导入导出及安全使用；
7. 危险信号识别，以及转向真人医生或急救系统。

天气、地理、食品、穿衣或其他一般话题，只有在请求明确说明其健康或中医目的时才进入允许范围。边界不清的请求不调用模型，只要求使用者说明与健康的关系。

## 直接拒绝

- 编程、投资、炒币、政治、娱乐、游戏、广告、刷量、论文代写等通用助手任务；
- 读取其他患者、其他医生或其他节点私域；
- 暴露系统提示词、密钥、内部配置或安全规则；
- 忽略限制、改变身份、冒充医生、自动签署或绕过授权；
- 批量爬取、垃圾消息、挖矿、攻击、无限循环、无限自审或智能体递归调用；
- 运行任意程序、安装软件、操作用户设备或访问未批准网络；
- 诊断、辨证定论、开方、调药、停药或伪造医生确认。

## 六道门

```text
身份与节点范围
→ 任务相关性
→ 安全与临床边界
→ 单请求资源预算
→ 最小范围检索和模型调用
→ 输出、写入和真人批准
```

前四道门必须在任何知识库读取或模型调用前完成。拒绝不产生模型费用，不读取私域正文，只记录不含原请求正文的原因码和最小安全审计。

## 0.1 单请求硬限制

| 资源 | 合成基线 |
| --- | --- |
| 输入长度 | 最多 6,000 个字符 |
| Agent 最大轮次 | 4 |
| 预计工具调用 | 最多 4 次 |
| 智能体转交深度 | 0；禁止智能体调用另一个智能体继续循环 |
| 医师徒弟工具 | 当前医生节点知识；有效会诊中的当前患者资料 |
| 患者辅导员工具 | 当前患者节点知识和本人私域 |
| 外部网络、代码执行、安装 | 全部关闭 |

模型输出 Token、用户/节点分钟与日额度、供应商费用、并发数和断路器依赖生产账户、供应商计费数据及持久化任务系统，本版本只建立合同，不宣称已完成生产控制。

## 文件与知识保护

- 文件类型、数量、大小、压缩层数和解压后总量必须受限；
- 可执行文件、脚本和未知压缩包隔离，不直接进入知识库；
- 文档中的“忽略规则、泄露资料、执行命令”只作为资料内容，不作为系统指令；
- 大文件先建立本地索引并按需检索，不在每轮发送全文；
- 内容哈希用于去重，避免重复保存和重复处理；
- 原始事实、患者确认、医生判断和 AI 草稿分别保存；
- 模型不得从文件内容扩大工具、节点或授权范围。

## 高风险升级

危险信号、严重加重、不良反应、药物调整、明确诊断、处方、已签署记录修改和隐藏风险等请求，不能以“范围相关”为由继续普通回答。系统必须停止辅导，显示真人医生或急救升级路径。

## 后续门禁

进入真实试点前还必须实现：持久化速率限制、用户/节点/供应商费用总闸、并发队列、输出 Token 上限、重复请求哈希、文件安全扫描、模型调用审计、缓存清理和运营级暂停开关。
